# ColorFighting 三原色水滴

用 RGB 三原色消除水滴的色彩學小遊戲。可以直接在手機瀏覽器玩，也可以「加入主畫面」安裝成 App（PWA，可離線遊玩）。

## 玩法

- 水滴從上方落下，顏色由 **紅 R、綠 G、藍 B** 組成。
- 按下水滴含有的原色，就把那個顏色扣掉。例如黃色（紅＋綠）按 R 之後會剩下綠色，再按 G 就蒸發。
- 顏色全部扣完，水滴蒸發並得分（每扣一個顏色得 10 × 關卡分）。
- 按鍵永遠作用在**最下面**的那一滴（白色虛線框標示）。
- 按錯（水滴裡沒有那個顏色）扣 5 分。
- 沒消掉的水滴會掉進濾杯，濾杯接滿 10 滴遊戲結束。
- 電腦上可以用鍵盤 R / G / B 操作，空白鍵或 P 暫停。

## 關卡

| 關卡 | 內容 |
|---|---|
| 1 | 單色：紅、綠、藍 |
| 2 | 單色，速度加快 |
| 3 | 混合色登場：黃＝紅＋綠、洋紅＝紅＋藍、青＝綠＋藍 |
| 4 | 混合色比例提高 |
| 5 | 白＝紅＋綠＋藍 |
| 6 以後 | 每關速度再提升、水滴更密集 |

每消除 10 滴進入下一關。玩到過的關卡會記在手機上，下次可以從最高關卡繼續，或在關卡選單挑任何已解鎖的關卡；接續時的分數是當初進入那一關時的分數。

## 發佈到 GitHub Pages

1. 到 repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約一分鐘後可在 `https://cnshow2025.github.io/colorfighting/` 開啟。

## 安裝到手機

- **iPhone（Safari）**：開啟網址 → 分享按鈕 → 「加入主畫面」。
- **Android（Chrome）**：開啟網址 → 右上選單 → 「安裝應用程式」或「加到主畫面」。

## 檔案

- `index.html`：整個遊戲（HTML + CSS + JavaScript）
- `manifest.webmanifest`：PWA 安裝設定
- `sw.js`：離線快取。更新遊戲後請把 `CACHE` 版本號加一，手機才會抓到新版。
- `icons/`：App 圖示
